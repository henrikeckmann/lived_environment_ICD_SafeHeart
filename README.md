B., Hansen, B. H., Rowlands, A. V., Langford, J. (2026). Associations of the lived environment and implanted cardioverter-defibrillator therapy with accelerometer-derived physical activity during long-term monitoring in the SafeHeart cohort", submitted at _Scientific Reports_.

Note that for the GENEAcore processing, I was using a proprietary version
of GENEAcore to get MIMS and Counts
